### Summary

**CVE-2026-109094** — Fixes integer overflow in `SProcXResQueryResourceBytes` (byte-swapped request path). On 32-bit servers, `numSpecs * sizeof(spec)` could wrap, pass length validation, and cause the swap loop to walk past the request buffer.

### Changes

### Assessment

- **Security fix (CVE):** Integer overflow in swap path — critical on 32-bit
- **Root cause:** `numSpecs * sizeof(xXResResourceIdSpec)` computed without overflow check before `REQUEST_FIXED_SIZE` validation
- **Attack vector:** Crafted byte-swapped XResQueryResourceBytes request with large `numSpecs` causing wraparound
- **Fix correct:** Explicit `UINT32_MAX / sizeof(spec)` check prevents wraparound; matches fix in `ProcXResQueryResourceBytes` (non-swapped path already had it)
- **Scope:** Large rewrite — but security-focused, not refactoring for its own sake
