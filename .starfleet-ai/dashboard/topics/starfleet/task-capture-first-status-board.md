Teil 1 von 2; Teil 2 = Plugin-Future-Task (starfleet/plugin-task-enforcement-future).\n\nUmfang (alles starfleetctl-Repo, ein Deployment-Zyklus via starfleet-bootstrap):\n\n1. CLI-Lifecycle (internal/task/task.go): neue Commands\n   - task begin <slug>: prueft Zuweisung auf eigenes Ship, status=in-progress, Timestamp-Log-Eintrag, comms status working --task <slug> --progress 0\n   - task log <slug> <text>: haengt '- <ISO> <ship>: <text>' an Topic-Body (Bearbeitungslog mit Timestamps), commit+reindex\n   - task progress <slug> <0-100> [note]: Progress ins Frontmatter + Log + comms status working --task --progress\n   - task done <slug>: status=done + Log + comms status idle\n   - Wiederverwendung von DoTopicLoad/DoTopicUpdate/commitAndReindex.\n\n2. Unattached-Flag (internal/comms/commands.go, records.go, json.go): comms status working|building ohne --task und ohne --note -> lauter Hinweis mit exaktem Folge-Befehl + unattached:true im StatusRecord (kein Abbruch, Plugin-Herzschlag bleibt heil). boardEntryJSON + Web bekommen das Flag.\n\n3. Web-UI (internal/web/web.go + index.html):\n   - GET /api/task/<slug> -> Frontmatter + Body (Work-Log)\n   - Task-Detail-Overlay (analog Ship-Overlay) mit Status, Assigned-to, Created, gerendertem Log, Log-Eingabefeld, Status-Dropdown\n   - Board-Karte: r.task klickbar -> oeffnet Overlay\n   - Tasks-Seite: Titel klickbar, Badges fuer interrupted, Warnbadge 'kein Task' bei working/building + unattached\n\n4. Timer/Sweep (internal/timer/system.go, internal/task/):\n   - task sweep-stale: fuer jedes stale Board-Ship (Status nicht idle/done) offene Tasks mit assigned-to==ship und status assigned|in-progress -> status=interrupted, Assignment bleibt, Log-Eintrag 'Schiff nicht mehr praesent (Heartbeat abgelaufen)', Batch-Commit + Event-Log\n   - neuer System-Verb sweep-stale + Cron-Timer */10 * * * * (idempotent via bootstrap gesichert, persistent)\n   - Fragmente: zurueckkehrendes Ship resumt interrupted-Tasks via task begin\n\n5. Skills/Anweisungen (fragments/): prominenter TASK-LIFECYCLE-Block (begin -> log/progress -> done), Nicht-Trivial-Definition, 'working = echte Arbeit, nicht nur Messages verarbeiten', Trivialarbeit via comms status working --note. Rollout via reindex + starfleet-bootstrap. Neudoku im starfleet-Skill.\n\n6.
