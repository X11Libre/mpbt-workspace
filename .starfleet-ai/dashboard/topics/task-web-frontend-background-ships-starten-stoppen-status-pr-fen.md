Erweiterung des Web-Frontends (starfleetctl web), um Background-Ships zu verwalten. UI-Elemente für: Background-Ship starten (Release, Client, Tier, Supervisor), Background-Ship stoppen, Status anzeigen (läuft/detached/gestoppt), attach/detach steuern. Backend: nutzt bestehende session run/attach/stop APIs. Akzeptanz: Im Web-Interface (neuer Tab 'Background') kann ein Background-Ship gestartet, gestoppt, per attach angezeigt und wieder detached werden; Status wird live angezeigt.
