Ships können Timer setzen, die ihnen zu bestimmter Zeit / Intervall / Timeout ein Signal via agent-bus senden. Timer sendet vom Schiff wählbaren Text. Akzeptanz: CLI/API für Timer setzen (einmalig, Intervall, Timeout), Timer persistiert über Neustarts, Signal kommt zuverlässig über agent-bus an, Timer-Verwaltung (liste, löschen, ändern).
